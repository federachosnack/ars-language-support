# ARS Language Support

Official Visual Studio Code extension providing syntax highlighting and structural language support for **ARS (`.ars`)** files.

## Features

* **Syntax Highlighting:** Full colorization for keywords, control flow, functions, classes, types, strings, numbers, and operators.
* **Code Folding & Indentation:** Automatic indentation and collapsible code blocks (`{}`, `[]`, `()`, and `#region` markers).
* **Auto-Closing Pairs:** Automatic closure for brackets, parentheses, and quotes.
* **Comment Toggling:** Native support for line comments (`//` and `#`) and block comments (`/* ... */`) via `Ctrl+/`.

## Usage

Simply open any file with the `.ars` extension and Visual Studio Code will automatically activate the **ARS** language mode.
